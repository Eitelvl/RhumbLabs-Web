## 1. Purpose of the Application

Aris is a meeting assistant for macOS. When the User starts it, it records the microphone and system audio, transcribes the conversation, tells apart the participants' voices and writes minutes with topics, decisions and next steps.

All processing happens on the User's device. The Application works with any calling application because it captures audio at the operating-system level; it does not connect to Zoom, Google Meet, Microsoft Teams, Discord or other services, and does not add participants or bots to meetings.

**6.1 Recording**
The Application only records when the User starts it, shows a visible indicator while recording, and asks the User to acknowledge a reminder about consent before the first recording.

**6.2 Transcription, Voice Separation and Minutes**
Generated by AI models running on the User's device.

**6.3 Meeting Alerts**
The optional "Let me know when a meeting starts" feature offers to record when another application starts using the microphone. It never starts a recording on its own.
